# Webapp Testing 技能

基于 Playwright 生成并执行自动化测试脚本，完成前端功能验证、界面调试与页面行为分析。

## 何时触发

- 用户请求编写测试时
- 用户请求自动化测试时
- 用户请求验证页面功能时
- 用户请求调试页面交互时

## 功能说明

### 测试脚本生成

- 生成 Playwright 测试脚本
- 支持多种浏览器（Chrome、Firefox、Safari）
- 支持移动端视口测试
- 支持 API 测试

### 页面对象模型（POM）

- 设计页面对象模型结构
- 封装页面元素和操作
- 提高测试代码可维护性

### 测试类型

1. **功能测试**
   - 表单提交验证
   - 导航流程测试
   - 用户交互测试

2. **视觉测试**
   - 截图对比
   - 响应式布局测试
   - 主题切换测试

3. **性能测试**
   - 页面加载时间
   - 资源加载分析
   - 网络请求监控

### 测试执行与报告

- 执行测试并生成报告
- 分析失败用例原因
- 提供修复建议

## 执行步骤

1. 分析目标页面或功能
2. 设计测试用例
3. 生成 Playwright 测试脚本
4. 配置测试环境
5. 执行测试
6. 分析结果并生成报告

## 注意事项

- 测试应该独立、可重复
- 使用有意义的测试描述
- 合理使用 before/after hooks
- 避免硬编码等待时间
