# Canvas Design 技能

代码手绘静态视觉内容（海报、封面、传单、名片、社交媒体配图），通过 HTML/CSS/SVG 实现精确的排版控制与图形设计。

## 何时触发

✅ **WHEN TO USE:**
- 用户需要「设计」海报、封面、传单等印刷/展示型视觉内容
- 用户需要精确的排版控制（字体、配色、构图）
- 用户需要代码输出的图形设计（非照片级写实图片）
- 用户提到「排版」、「配色」、「构图设计」、「设计封面」

❌ **WHEN NOT TO USE:**
- 用户要「生成照片级写实图片」→ 用 ai-image-generation
- 用户要「AI生图」、「AI画图」、「概念艺术」→ 用 ai-image-generation
- 用户要生成数据图表 → 用 data-analysis（已吸收 chart-visualization）
- 用户要生成 UI 界面 → 用 frontend-skill 或 frontend-design

⚠️ **EDGE CASES:**
- 用户说「生成一张海报图」→ 先确认：是代码排版设计（canvas-design）还是 AI 照片级生图（ai-image-generation）
- 用户说「做一张封面」→ 关键词含「照片」「写实」→ 走 ai-image-generation；含「设计」「排版」→ 走 canvas-design

## 功能说明

### 设计类型

1. **海报设计**
   - 活动海报
   - 宣传海报
   - 产品海报

2. **封面设计**
   - 书籍封面
   - 报告封面
   - 演示文稿封面

3. **社交媒体**
   - 公众号封面
   - 社交媒体配图
   - 信息图

4. **印刷品**
   - 名片
   - 传单
   - 折页

### 设计要素

- **构图**：平衡、对比、焦点
- **配色**：主色、辅色、点缀色
- **字体**：标题字体、正文字体
- **图形**：形状、图标、插图
- **留白**：呼吸感、层次感

### 设计原则

- 视觉层级清晰
- 信息传达准确
- 风格统一协调
- 原创性保证

### 技术实现

- HTML Canvas
- SVG
- CSS 绘图
- 图片合成

## 执行步骤

1. 理解设计需求和主题
2. 确定设计规格和尺寸
3. 设计构图布局
4. 选择配色方案
5. 选择字体和排版
6. 添加图形元素
7. 调整细节和优化
8. 导出最终作品

## 注意事项

- 保持原创性
- 注意版权问题
- 考虑输出场景
- 预留修改空间
