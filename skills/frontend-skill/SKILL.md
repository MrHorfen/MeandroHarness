# Frontend Skill 技能

构建企业级功能型前端页面（后台管理、数据面板、表单工具页），通过规范的信息层级与排版提升视觉效果，强调克制简洁、功能优先的设计哲学。

## 何时触发

✅ **WHEN TO USE:**
- 用户需要构建「后台管理」页面（CRUD、数据表格、筛选表单）
- 用户需要「数据面板」/「Dashboard」/「仪表盘」类页面
- 用户需要「表单工具页」（设置页、配置页、录入页）
- 用户强调「信息层级规范」、「高效操作」、「简洁风格」
- 用户提到「管理后台」、「后台系统」、「数据管理」

❌ **WHEN NOT TO USE:**
- 用户要「营销着陆页」、「品牌官网」→ 用 frontend-design
- 用户要「炫酷动画」、「高视觉冲击力」→ 用 frontend-design
- 用户要「好看的页面」但没有功能需求 → 用 frontend-design
- 设计海报/封面 → 用 canvas-design

⚠️ **EDGE CASES:**
- 用户说「做个页面」→ 先确认：功能型（后台/表单/数据）→ frontend-skill；创意型（营销/品牌/展示）→ frontend-design
- 用户说「做个漂亮的页面」→ 关键词含「后台」「管理」「数据」→ frontend-skill；含「营销」「品牌」「推广」→ frontend-design

## 功能说明

### 设计原则

1. **信息层级**
   - 主标题 > 副标题 > 正文 > 辅助信息
   - 视觉权重合理分配
   - 清晰的内容结构

2. **排版规范**
   - 合理的字体大小层级
   - 适当的行高和字间距
   - 一致的边距和对齐

3. **克制的设计**
   - 避免过度装饰
   - 简洁的视觉元素
   - 功能优先于形式

4. **响应式设计**
   - 移动端优先
   - 合理的断点设置
   - 弹性布局

### 技术实现

- 语义化 HTML 结构
- CSS 模块化组织
- 组件化开发
- 状态管理规范

### 可访问性

- 键盘导航支持
- 屏幕阅读器友好
- 颜色对比度合规
- ARIA 属性正确使用

## 执行步骤

1. 分析页面需求和内容
2. 设计信息层级结构
3. 创建语义化 HTML
4. 实现样式和布局
5. 添加交互功能
6. 优化响应式适配
7. 检查可访问性

## 注意事项

- 保持设计一致性
- 注重用户体验
- 代码可维护性
- 性能优化
