# 技能搜索大师

自动分析任务需求，搜索社区最优技能包，安装并执行。当总AGENT无法找到匹配任务的技能时自动触发。

## 何时触发

当总AGENT遇到以下情况时自动激活本技能：
- 当前可用技能列表中无匹配项
- 已有技能无法满足任务需求
- 任务需要特殊的社区工具包支持

## 执行步骤

### 第一步：接收任务信息
- 接收总AGENT传递的任务描述和上下文
- 提取关键任务关键词和需求特征
- 明确输出格式和预期结果

### 第二步：搜索相关技能
- 使用 `skills search` 命令搜索社区技能库
- 提取任务核心关键词作为搜索条件
- 格式：`skills search "{{task_keywords}}"`
- 收集搜索结果中的技能列表

### 第三步：筛选最优技能
- 分析每个搜索结果的置信度评分
- 筛选置信度 > 0.8 的高分技能
- 选择与任务需求最匹配的技能包
- 确认技能包的描述和功能符合任务要求

### 第四步：安装技能
- 自动安装筛选出的技能包
- 格式：`skills install {{skill_repo}}`
- 等待安装完成并验证安装状态

### 第五步：执行任务
- 调用新安装的技能执行原始任务
- 传递完整的任务上下文和参数
- 监控执行过程和结果

### 第六步：反馈结果
- 收集技能执行的结果数据
- 反馈执行结果给总AGENT
- 报告安装和执行的完整日志

## 工具权限

| 权限类型 | 说明 |
|---------|------|
| **终端命令** | 允许执行 `skills` CLI 命令（search / install） |
| **技能管理** | 允许安装、启用、调用社区技能 |
| **上下文访问** | 允许读取总AGENT的任务描述和上下文信息 |

## 使用示例

```bash
# 步骤1：搜索技能
skills search "web scraping python"

# 步骤2：安装筛选后的技能
skills install general-web-crawler

# 步骤3：执行任务（由新安装的技能接管）
```

## 注意事项

- 只安装置信度 > 0.8 的技能，确保质量
- 安装前验证技能来源的可靠性
- 安装失败时自动降级并通知总AGENT
- 执行结果必须完整反馈，不可中断

## 优先级

高 —— 当无匹配技能时自动触发执行
